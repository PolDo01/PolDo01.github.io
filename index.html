Job Search

Closed source

Closed-source job board aggregator: 5 APIs, ~16.5k jobs, medallion pipeline

A scheduled pipeline that pulls remote jobs from five free job-board APIs (Remotive, Jobicy, Himalayas, Arbeitnow, Greenhouse), normalizes them into one schema with a composite key, loads them into SQLite, and tags every row with a remote-work scope (global / multi-region / region-only). PySpark transforms the data into clean marts, and a daily analysis produces a shortlist of apply-able roles for APAC-eligible candidates.

Stack
python, sqlite, pyspark, requests
Source
Closed. Architecture and code available on request.
